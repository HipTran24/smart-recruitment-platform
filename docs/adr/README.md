# Architecture Decision Records

ADR ghi lại quyết định kỹ thuật có ảnh hưởng lâu dài: bối cảnh, lựa chọn, lý do và hệ quả. ADR không phải nơi ghi todo nhỏ hoặc ghi chú cá nhân.

## Quy ước

- Tên file: `NNNN-ten-quyet-dinh.md`, ví dụ `0001-modular-monolith.md`.
- ADR đã được chấp thuận không bị viết lại lịch sử. Nếu quyết định thay đổi, tạo ADR mới thay thế và liên kết tới ADR cũ.
- Trạng thái hợp lệ: `Proposed`, `Accepted`, `Superseded`, `Deprecated`.

## Mẫu

```markdown
# ADR NNNN: Tên quyết định

> Trạng thái: Proposed | Accepted | Superseded | Deprecated
> Ngày: YYYY-MM-DD

## Bối cảnh

## Quyết định

## Hệ quả

## Các lựa chọn đã cân nhắc
```
